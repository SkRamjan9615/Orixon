Quick Installation Guide

1. Android Phone / Tablet

Tap "Download for Android Phone" above to download Orixon.apk, open the downloaded file, and tap Install.

2. Android TV / Google TV

Open this page on your TV browser or Downloader app, download Orixon-Android-TV.apk, and install to launch ORIXON from your TV home screen.

3. Windows & macOS

Download the Windows or macOS package above, extract the archive, and run the ORIXON launcher executable.

4. In-App Auto Updates

Inside ORIXON, go to Settings ➔ About and tap "Update" beside the version badge anytime to update directly inside the app.
