# Contributing to ORIXON

Thank you for your interest in contributing to **ORIXON** (`org.orixon.app`)!

## Development Setup
1. Fork `https://github.com/SkRamjan9615/orixon` and clone your fork.
2. Run `flutter pub get`.
3. Format your Dart code with `dart format .` and verify zero errors via `flutter analyze`.
4. Submit a Pull Request describing your changes clearly.
