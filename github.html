2. Deep-Dive Engineering Modules in SkRamjan9615/orixon

A. Live TV Engine & M3U / M3U8 Playlist Studio (lib/features/live_tv/)

Unlike basic IPTV players that buffer on high-bitrate streams, ORIXON allocates a dedicated 128 MB RAM stream cache (cache-secs=60) inside its media_kit / libmpv pipeline. The built-in M3U parser natively extracts #KODIPROP:inputstream.adaptive.license_key ClearKey DRM keys, splits #EXTVLCOPT and #EXTHTTP custom headers, probes streams across 9 smart User-Agent profiles, and allows users to filter, manage, and export category-specific .m3u playlists.

B. 4K HDR10+ & Hardware-Gyroscope VR 360° / 3D Headset Media Hub (lib/features/local_media/)

Designed as an all-format video player supporting MKV, MP4, AVI, MOV, WEBM, TS, HEVC (H.265), AV1, and VP9 with hwdec=auto-safe hardware decoding. It features ultra-transparent glass controls, zero-lag timeline scrubbing, dedicated left/right 22% screen edge zones for 0–200% hardware window brightness and 0–200% audio boost with Dolby Atmos passthrough, native Android Picture-in-Picture (PiP), and a 60fps hardware SensorManager gyroscope bridge for immersive VR 360° and Side-by-Side (SBS) 3D headsets.

C. Global Cloud Share & Android TV File Sharing Suite (lib/features/file_hub/)

ORIXON eliminates the need for separate file transfer apps on Android TV and smartphones by integrating five send-and-receive protocols: Global Cloud Share (instant 6-digit Receive Code and direct browser download link), Receive File by Link, Orixon Direct Beam (high-speed local Wi-Fi transfer), Wi-Fi Web Portal (:8888), and Wireless FTP Server (:2121), paired with an Internal/SD/USB OTG file explorer and ZIP archiver.

D. Smart TV OS Launcher, Hardware Gyro Rotation & DuckDuckGo WebX Browser

The OS shell adapts seamlessly between 10-foot Android TV D-Pad navigation and smartphone touch interfaces. On smartphones, a native Kotlin OrientationEventListener drives 2-way landscape sensor rotation when TV Interface mode is active or system Auto-Rotate is off, and full 4-way 360-degree rotation when Auto-Rotate is enabled. It also includes Universal Voice Search auto-play, full JSON backup and restore via File Hub, a silent in-app OTA APK updater, and the ad-blocking DuckDuckGo WebX privacy browser.
