# Security Policy

## Supported Versions
| Version | Supported |
| :--- | :--- |
| `1.1.x` (`org.orixon.app`) | Yes |
| `< 1.0.0` | No |

## Reporting a Vulnerability
If you discover a security issue in ORIXON (including file sharing, WebX browser, or M3U parsing), please open a private security advisory on GitHub or report via GitHub Issues without posting exploit details publicly. All verified reports receive a response within 72 hours.
